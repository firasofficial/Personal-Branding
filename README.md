# Muhammad Firas — Professional Personal Branding Portfolio

A modern, high-performance personal branding portfolio website designed for **Muhammad Firas**, Senior Product Designer & Creative Technologist. Specializing in spatial UI, high-performance design systems, and next-generation interactive digital experiences.

---

## ✨ Features

- **Interactive Antigravity Hero Canvas**: Real-time interactive particle physics and fluid canvas background.
- **Glassmorphism & Spatial Design**: Cutting-edge visual design system with dark mode aesthetics, dynamic glow accents, and responsive typography.
- **Interactive 3D Tilt Cards**: Smooth 3D perspective tilt physics on project showcase cards.
- **Dynamic Profile Customizer**: Real-time client-side customization for brand styling and portfolio details.
- **Synthesized Audio Effects (Sound FX)**: Interactive audio feedback powered by Web Audio API.
- **Full Responsiveness**: Seamless experience across mobile, tablet, and ultra-wide desktop screens.

---

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup.
- **Vanilla CSS3**: Modern design tokens, CSS variables, glassmorphic blurs, and micro-animations.
- **Vanilla JavaScript (ES6+)**: High-performance canvas rendering, audio synthesis, and interactive controls without heavy external frameworks.

## 🚀 Getting Started

### Local Setup

To preview the portfolio locally, you can open `index.html` directly in your browser, or run a local static server:

#### Option 1: PowerShell Server
Run the included PowerShell script:
```powershell
.\server.ps1
```
Then visit `http://localhost:8000` (or the port specified in terminal).

#### Option 2: Python HTTP Server
```bash
python -m http.server 8000
```

#### Option 3: VS Code Live Server
Right-click on `index.html` and select **"Open with Live Server"**.
